Here is a complete interactive to-do list app, fully embedded in HTML.

1. A <nav> bar with title "My Tasks" and a live counter <span id="count"> showing the number of tasks.
2. A text <input id="task"> and an "Add" <button id="add> that append the input's text as a new <li> in a <ul id="list> when clicked (wire with addEventListener).
3. Each added <li> must include a "Delete" button that removes that item and updates the counter.
4. A <form id="filter"> with radio buttons All/Active to filter the list, with an onsubmit handler using preventDefault.
5. Minimal embedded CSS in <style> and all logic in <script>. Keep CSS short; prioritize a COMPLETE working app with correct JavaScript.

Output HTML, fully closed with </html>.
